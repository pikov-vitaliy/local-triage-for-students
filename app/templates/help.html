Первый запуск

Стенд запускается командой npx local-triage: она ставит Python, создаёт базу и открывает в браузере список проектов; справка открывается кнопкой «Справка» в шапке. Окно терминала держит приложение – не закрывайте его, пока работаете; остановка – Ctrl+C. Где лежат база и папка кода, показывает npx local-triage --where.

Модель

Модель предлагает вердикт по находке SAST, решение принимаете вы. Ollama на своём компьютере – при видеокарте от 16 ГБ (заготовка). Иначе – DeepSeek со своим ключом (заготовка); поставьте лимит расхода ключа у провайдера. Код уходит внешнему провайдеру только после вашей отметки «код не секретный» на странице предпросмотра.

Примеры

На странице «Примеры» – десять открытых уязвимых приложений и выдуманная Demo Library. Исходники скачиваются с GitHub по закреплённому коммиту и сверяются по хешу. Папка примера после скачивания ваша: правьте код в редакторе, стенд её не меняет. «Скачать заново» кладёт чистую копию рядом.

Разбор SAST

  1. Прочитайте правило и класс CWE.
  2. Посмотрите код вокруг строки; «Открыть в VS Code» открывает файл на этой строке.
  3. Проследите путь данных: приходят ли они извне и доходят ли до опасной операции без проверки.
  4. Сравните вывод с вердиктом модели и примите решение: «Ложное срабатывание» с причиной, «Подтверждаю дефект» или «Отложить».

Уязвимости компонентов

Для каждой находки SCA оцените версию компонента, есть ли исправленная версия и используется ли уязвимая функция в коде примера. Решения: «Обновить», «Риск принят» с обоснованием, «Ложное срабатывание».

Лицензии компонентов

Находки о лицензиях – компоненты с лицензией вне разрешённого перечня учебной политики: сильный копилефт (GPL, AGPL) – High, слабый (LGPL, MPL, EPL, OFL) – Medium, прочие и «лицензия не установлена» – Low. Они в общем списке находок, вид «SCA-license».

Дефект

Хороший дефект называет файл и строку, объясняет путь данных от источника до опасной операции, последствия и исправление: параметризованный запрос, экранирование, проверку пути, обновление компонента.

Глоссарий

SAST
статический анализ исходного кода без запуска программы
SCA
композиционный анализ: сторонние компоненты, их уязвимости и лицензии
Срабатывание
место в коде или компонент, на которые указал анализатор
Ложное срабатывание
срабатывание без реальной уязвимости
Триаж
разбор срабатываний: подтвердить, отклонить, отложить
CWE
перечень классов слабостей ПО
CVE
идентификатор конкретной известной уязвимости
CVSS
оценка тяжести уязвимости от 0 до 10
Копилефт
условие лицензии: производное ПО распространяется на тех же условиях
ASOC
Application Security Orchestration and Correlation – класс систем, которые собирают результаты всех анализаторов защищённости в одном месте, убирают повторы и ведут решения и дефекты; пример – AppSec.Hub
Выгрузка Hub
книга Excel с результатами анализа в формате AppSec.Hub
