Учебные примеры

Открытые уязвимые приложения на разных языках с готовой выгрузкой формата Hub: находки SAST, уязвимости компонентов (SCA) и лицензии компонентов. Исходники скачиваются с GitHub по закреплённому коммиту и сверяются по хешу. Папка примера после скачивания ваша: правьте код в редакторе, стенд её не трогает.

Начало работы

  1. Модель. На компьютере с видеокартой от 16 ГБ – Ollama: заготовка «Ollama на этом компьютере» (модель gpt-oss:20b). Иначе – DeepSeek: заготовка DeepSeek, нужен свой ключ API с лимитом расхода.
  2. Профиль для примеров. {{ start.mode }} {% if start.checks %}{% for c in start.checks %}{{ c }}{% endfor %}{% if start.chosen %} · проверить профиль{% endif %}{% endif %}
  3. Пример. Скачайте исходники примера и нажмите «Создать проект»: выгрузка загрузится, кодовые базы свяжутся с папкой примера.
  4. Разбор. Запустите триаж SAST на странице проекта или разбирайте находки сами: смотрите код в карточке или в VS Code, отмечайте «Ложное срабатывание» или «Подтверждаю дефект»; уязвимости компонентов – на вкладке SCA, лицензии – в общем списке находок.
