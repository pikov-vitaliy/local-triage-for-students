## [0.10.0.dev32] – 2026-11-21

Первый публичный снимок. Приложение для занятий по разбору срабатываний статического анализа (SAST) и анализа состава
компонентов (SCA): находки разбираются в браузере, приложение показывает код, справочники CWE, CAPEC и БДУ ФСТЭК России
и ответ модели, решение принимает обучающийся.

- Два варианта установки: Docker-установка (в том числе с подключением к AppSec.Hub) и учебный стенд из пакета npm без
  Docker – свои Python и PostgreSQL в служебной папке, запуск одной командой.
- Модели: локальная Ollama и внешние провайдеры по профилям.
- Демо-проект с вымышленными данными.
