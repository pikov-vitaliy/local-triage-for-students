# Журнал изменений

Все заметные изменения учебного стенда «Локальный триаж» записываются в этот файл.

Формат – [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии – по
[семантическому версионированию](https://semver.org/lang/ru/).

## [Не выпущено]

## [0.10.0.dev37] – 2026-11-22

- Стенд, запущенный с `--local-only`: внешний «Профиль для примеров» (например DeepSeek, выбранный раньше) новому
  проекту из примера не назначается – проект остаётся с профилем по умолчанию, и стенд говорит почему. Раньше проект
  получал внешний профиль, и разбор отказывал.
- README пакета и README репозитория: предупреждения GitHub об уязвимостях относятся к снимкам зависимостей учебных
  примеров, а не к самому стенду.
- «Журнал»: состояние прогона («завершён») и «пропуски 0», «Нет замера» не рвутся по буквам и по строкам.

## [0.10.0.dev36] – 2026-11-22

- Профиль внешнего API (например DeepSeek) можно сделать профилем по умолчанию для разбора кода; код ему уходит только
  проектам с отметкой «код не секретный», остальным разбор откажет с объяснением. Локальный или сетевой сервер API
  чат-завершений умолчанием для кода не назначается: разбор кода с ним не запускается.
- Карточка находки: «Скопировать путь» и «Открыть в VS Code» – в строке сведений о срезе кода, полный путь – в
  подсказке кнопок. Отдельные строки с полным путём сдвигали код вниз, и строка срабатывания уходила под нижнюю панель
  на экранах 1280×620, 1440×900 и 1536×864.
- Карточка находки: блок «Текущий файл в клоне, без масок» (при показе без масок – умолчание с dev35) стоит под
  шагами 1–3, а не в закреплённой колонке кода: колонка выходила выше экрана, и «строка N» из разбора сдвигала
  страницу.
- Заготовка DeepSeek сразу заполняет раздел «Дополнительно» рекомендуемыми значениями (сверены с документацией
  DeepSeek 22.11.2026): ответ json_object, рассуждение включено, уровень high, окно контекста 1 000 000, предел ответа
  65536, 12 шагов поиска, срок обращения 600 с, повтор после обрыва, поиск /v1/tools/search и /v1/tools/fetch. У каждого
  поля – подсказка простыми словами; у созданного раньше профиля – кнопка «Подставить рекомендуемые значения DeepSeek».
- Demo Library получает отметку «код не секретный» при создании, как десять скачиваемых примеров: её код выдуманный,
  написан для приложения (слово владельца 22.11.2026). Отметка действует, только когда внешние провайдеры включены, и
  снимается в параметрах проекта. README пакета, руководство студента и справка говорят об этом (раньше тексты
  говорили, что отметку у примеров ставит студент).
- Проверка стенда агентами по сценариям студента (22.11.2026), исправлено:
  - на учебном стенде нет шага «Состояние Hub», кнопок «Синхронизировать» и текста «Адрес Hub не задан»: вкладка
    «Дефекты» объясняет, что текст дефекта копируется из карточки находки как образец;
  - пустой список проектов стенда ведёт в «Примеры» (кнопка «Открыть «Примеры»»);
  - дефект SAST без названия команды: причина видна в карточке, со ссылкой на поле в «Настройках»;
  - модель проекта без своей модели – модель профиля, которым пойдёт разбор («– из профиля «…»»), в шапке проекта,
    «Параметрах проекта», списке проектов и по умолчанию в «Запустить триаж отмеченных»; «Настройки» говорят, какой
    профиль по умолчанию, и проверяют Ollama всегда своим профилем;
  - карточка с внешним профилем без списка моделей просит проверить ключ и адрес профиля, а не Ollama;
  - свежая карточка без решения не предупреждает «в Hub уйдёт другой»;
  - находки о лицензиях: карточка объясняет уровни учебной политики, тексты не обещают разбора, которого нет; на
    странице проекта SCA и лицензии считаются отдельно, как на вкладке SCA;
  - карточка SCA отправляет за заданием агенту в «Компоненты», а не на устаревший якорь страницы SCA; у
    неисследованного компонента – «Уязвимости: не исследован» вместо 0; подписи «Решение по компоненту», подсказки
    об исследовании – с заготовкой DeepSeek;
  - «Справочники»: ссылка на сайт БДУ, без служебных слов; «Журнал»: надзаголовок «Модели»;
  - «Примеры»: «Скачать заново» – своё сообщение; соответствие кодовой базы, поставленное при создании проекта из
    примера, подписано «из примера» (сброс ручных соответствий по-прежнему сбрасывает и его, подтверждение считает
    его); лишняя точка в «Начале работы» и обосновании отметки;
  - шапка на ширине 761–1000 пикселей переносится, а не уезжает вбок; «Начало работы» помещается в 360 пикселей;
  - руководство студента и справка: подписи как в интерфейсе («Версия исправления (Hub)», «SCA, лицензии»),
    название команды для дефекта.

## [0.10.0.dev35] – 2026-11-21

- Справочники: понятный ход загрузки. После выбора файла рамка пишет имя, размер и «Теперь нажмите «Загрузить»»,
  чужой файл (не .zip) – сразу; во время разбора – шаги «Файл получен», «Разбор и запись», «Готово» и счётчик времени,
  объяснение, почему кнопки недоступны; итог – «Готово: … загружен, записей – N» или «… не загружен: причина; прежний
  справочник не изменился»; у загруженного справочника – «Загружен и работает». Ссылка на архив CWE.
- Шапка в одну строку: знак, название и меню на одной линии на экранах от 1000 пикселей; на средних экранах меню без
  значков, крошки сокращаются; на телефоне меню переносится, страница не уезжает вбок.
- Раздел «Так задумано» в README пакета, руководстве студента и справке стенда: что выглядит как ошибка, но
  намеренно (свёрнутые подробности разбора, редкие действия в свёрнутых блоках, один проект на пример,
  справочники по одному, запуск после снятия через Диспетчер задач).
- Маскирование секретов при показе кода по умолчанию выключено: новые проекты, проекты примеров и демо показывают
  код как есть, флажок «Маскировать секреты при показе» при создании снят. Включает его оператор в параметрах
  проекта. У уже созданных проектов значение не меняется.
- Проекты учебных примеров получают отметку «код не секретный» при создании: код примеров открытый, внешний
  провайдер (если включён на установке) доступен сразу; отметка снимается в параметрах проекта.
- В меню – пункт «Проекты»: к своим проектам можно вернуться с любой страницы, не только по логотипу.
- Логотип Local Triage: знак «сортировка находок» (три полосы по важности и отметка «проверено»), надпись на
  английском, новый значок вкладки.

## [0.10.0.dev33] – 2026-11-21

- Страница «Примеры»: десять открытых уязвимых приложений (OWASP Juice Shop, OWASP WebGoat, PyGoat, OWASP NodeGoat,
  DVWA, OWASP RailsGoat, DVGA, go-test-bench, VulnerableLightApp, OWASP crAPI) и Demo Library. У каждого – выгрузка
  формата Hub: находки SAST, уязвимости компонентов (SCA) и лицензии компонентов. Исходники скачиваются с GitHub по
  закреплённому коммиту и сверяются по хешу; «Создать проект» связывает кодовые базы с папкой примера.
- Карточка находки: путь к файлу на компьютере и «Открыть в VS Code».
- Заготовки профилей DeepSeek и Ollama, «Профиль для примеров» и панель «Начало работы». Код уходит внешней модели
  только после отметки «код не секретный», которую ставит сам обучающийся.
- Справка с глоссарием в новой вкладке; тема оформления по времени суток.
- Руководства студента и преподавателя (`docs/stand-student-guide.md`, `docs/stand-teacher-guide.md`).

## [0.10.0.dev32] – 2026-11-21

Первый публичный снимок. Приложение для занятий по разбору срабатываний статического анализа (SAST) и анализа состава
компонентов (SCA): находки разбираются в браузере, приложение показывает код, справочники CWE, CAPEC и БДУ ФСТЭК России
и ответ модели, решение принимает обучающийся.

- Два варианта установки: Docker-установка (в том числе с подключением к AppSec.Hub) и учебный стенд из пакета npm без
  Docker – свои Python и PostgreSQL в служебной папке, запуск одной командой.
- Модели: локальная Ollama и внешние провайдеры по профилям.
- Демо-проект с вымышленными данными.
