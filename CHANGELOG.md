# Журнал изменений

Все заметные изменения учебного стенда «Локальный триаж» записываются в этот файл.

Формат – [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии – по
[семантическому версионированию](https://semver.org/lang/ru/).

## [Не выпущено]

## [0.10.0.dev35] – 2026-11-21

- Справочники: понятный ход загрузки. После выбора файла рамка пишет имя, размер и «Теперь нажмите «Загрузить»»,
  чужой файл (не .zip) – сразу; во время разбора – шаги «Файл получен», «Разбор и запись», «Готово» и счётчик времени,
  объяснение, почему кнопки недоступны; итог – «Готово: … загружен, записей – N» или «… не загружен: причина; прежний
  справочник не изменился»; у загруженного справочника – «Загружен и работает». Ссылка на архив CWE.
- Шапка в одну строку: знак, название и меню на одной линии на экранах от 1000 пикселей; на средних экранах меню без
  значков, крошки сокращаются; на телефоне меню переносится, страница не уезжает вбок.
- Раздел «Так задумано» в README пакета, руководстве студента и справке стенда: что выглядит как ошибка, но
  намеренно (свёрнутые подробности разбора, редкие действия в свёрнутых блоках, один проект на пример,
  справочники по одному, запуск после снятия через Диспетчер задач).
- Маскирование секретов при показе кода по умолчанию выключено: новые проекты, проекты примеров и демо показывают
  код как есть, флажок «Маскировать секреты при показе» при создании снят. Включает его оператор в параметрах
  проекта. У уже созданных проектов значение не меняется.
- Проекты учебных примеров получают отметку «код не секретный» при создании: код примеров открытый, внешний
  провайдер (если включён на установке) доступен сразу; отметка снимается в параметрах проекта.
- В меню – пункт «Проекты»: к своим проектам можно вернуться с любой страницы, не только по логотипу.
- Логотип Local Triage: знак «сортировка находок» (три полосы по важности и отметка «проверено»), надпись на
  английском, новый значок вкладки.

## [0.10.0.dev33] – 2026-11-21

- Страница «Примеры»: десять открытых уязвимых приложений (OWASP Juice Shop, OWASP WebGoat, PyGoat, OWASP NodeGoat,
  DVWA, OWASP RailsGoat, DVGA, go-test-bench, VulnerableLightApp, OWASP crAPI) и Demo Library. У каждого – выгрузка
  формата Hub: находки SAST, уязвимости компонентов (SCA) и лицензии компонентов. Исходники скачиваются с GitHub по
  закреплённому коммиту и сверяются по хешу; «Создать проект» связывает кодовые базы с папкой примера.
- Карточка находки: путь к файлу на компьютере и «Открыть в VS Code».
- Заготовки профилей DeepSeek и Ollama, «Профиль для примеров» и панель «Начало работы». Код уходит внешней модели
  только после отметки «код не секретный», которую ставит сам обучающийся.
- Справка с глоссарием в новой вкладке; тема оформления по времени суток.
- Руководства студента и преподавателя (`docs/stand-student-guide.md`, `docs/stand-teacher-guide.md`).

## [0.10.0.dev32] – 2026-11-21

Первый публичный снимок. Приложение для занятий по разбору срабатываний статического анализа (SAST) и анализа состава
компонентов (SCA): находки разбираются в браузере, приложение показывает код, справочники CWE, CAPEC и БДУ ФСТЭК России
и ответ модели, решение принимает обучающийся.

- Два варианта установки: Docker-установка (в том числе с подключением к AppSec.Hub) и учебный стенд из пакета npm без
  Docker – свои Python и PostgreSQL в служебной папке, запуск одной командой.
- Модели: локальная Ollama и внешние провайдеры по профилям.
- Демо-проект с вымышленными данными.
