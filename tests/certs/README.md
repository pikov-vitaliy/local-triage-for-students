# Сертификаты для тестов

Только для тестов проверки TLS у класса доверия `external` (`tests/test_external_trust.py`): выдуманный
удостоверяющий центр «local-triage test CA» (`ca.pem`, без закрытого ключа – он удалён после выпуска) и сертификат
сервера `external-test.example` (`server-cert.pem`) и его закрытый ключ без PEM-заголовков (`server-key.b64`): файл с
сертификатом и ключом собирает `tests/cert_files.py` во временную папку при запуске тестов. Ни к одному настоящему серверу отношения не
имеют; приложение их не использует – тест сам подставляет `ca.pem` вместо системного хранилища.
